# .ai-memory

Persistent project memory for **go-ecommerce**. Read these in order at the start of a session.

## Read order

1. `onboarding.md` — entry point: what this is, golden rules, how to run & test
2. `context.md` — purpose, goals, scope, constraints, glossary
3. `architecture.md` — system overview, stack, components, data model, principles
4. `decisions.md` — ADR log
5. `progress.md` — phase, completion, milestones
6. `active-tasks.md` — what's in flight right now
7. `session-log.md` — append-only history

`tasks/` holds one file per detailed task.

## Important

**Commit this directory to git.** It is shared project knowledge, not local scratch.
